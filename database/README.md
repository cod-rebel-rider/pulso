# database

Destinado aos recursos de persistência do PULSO (a partir da **Fase 02 — Banco de Dados**):

- esquema e migrações versionadas do banco SQLite;
- scripts auxiliares de banco.

**Importante:** o *arquivo de dados do usuário* ficará **fora deste repositório** (no diretório de dados do sistema operacional). Aqui ficam apenas recursos versionados do projeto.

Consulte `docs/banco-de-dados.md` para a estratégia completa.
