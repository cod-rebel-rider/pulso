# src/modules — Módulos de Funcionalidade

Destinado aos módulos independentes do PULSO, a serem implementados nas fases futuras:

**Missões · Projetos · Jogador · Status · Progressão · Finanças · Loja · Serviços · Habilidades · Música · Mapa · Conquistas**

Cada módulo deverá expor uma **interface clara** para o restante do sistema (ver `docs/arquitetura.md`, seção "Comunicação").

**Nenhum módulo é implementado na Fase 00** — esta pasta existe apenas para receber a estrutura definida da arquitetura.
